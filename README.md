# RH Forum

**RH Forum** — русскоязычный форум сообщества RH Media. Проект основан на открытом исходном коде [Discussion Kit](https://github.com/NotReeceHarris/discussion-kit) и распространяется с сохранением исходной лицензии MIT.

## Возможности

- Разделы и обсуждения на базе GitHub Discussions.
- Темы, статьи, комментарии и ответы.
- Реакции, голоса, закреплённые темы и поиск.
- Профили участников и система репутации.
- Модерация: авторы и владельцы репозитория могут редактировать и удалять публикации.
- Публичный архив для чтения без входа.
- Адаптивный интерфейс, русская локализация и тёмная тема RH.

## Архитектура и ограничения

Сайт собирается в статические файлы и размещается на **GitHub Pages**. Отдельный сервер и собственная база данных не нужны. Данные обсуждений хранятся в GitHub Discussions репозитория `RAHER458/website`.

- Чтение без входа доступно через архивную копию после первого запуска синхронизации.
- Для создания тем, комментариев и реакций участник входит через GitHub Personal Access Token с правами чтения/записи Discussions.
- Главный администратор форума: **RAHER458**. Он является владельцем репозитория; серверные права модерации GitHub определяются реальными правами репозитория, а не только визуальным бейджем.
- Для включения форума необходимо включить Discussions в Settings → General → Features и создать категории обсуждений.

## Публикация

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует его на GitHub Pages по адресу:

https://raher458.github.io/website/

В Settings → Pages выбери **GitHub Actions** в качестве источника публикации.

## Локальная разработка

```bash
npm ci
npm run dev
```

Проверка и сборка:

```bash
npm run check
npm test
BASE_PATH=/website npm run build
```

## Настройка

Основные параметры бренда, репозитория и главного администратора находятся в `forum.config.ts`.

Исходные материалы и лицензия оригинального проекта сохранены в репозитории.
